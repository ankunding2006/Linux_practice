## Day 1：文件描述符与文件 I/O

学习：

1. 文件描述符 FD
    - 什么是 FD
    - stdin = 0
    - stdout = 1
    - stderr = 2
    - 为什么 Linux 中很多 I/O 对象都可以通过 FD 操作

2. open()
    - 打开文件
    - flags
    - 返回值

3. read()
    - buffer
    - count
    - 返回实际读取字节数
    - 返回 0 表示 EOF
    - 返回 -1 表示错误

4. write()
    - 写入数据
    - 返回实际写入字节数
    - 为什么不能默认一次 write 就写完

5. close()
    - 关闭 FD
    - 为什么资源需要释放

实践：

- 写一个程序读取 txt 文件并打印到终端
- 使用：
  open()
  read()
  write()
  close()
